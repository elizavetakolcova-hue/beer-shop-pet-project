# Физическая модель

## Нормализация
- Таблицы приведены в форму 3ФН
- В таблице Товары_в_поставке первичный ключ составной: (Код поставки, Код товара). Неключевое поле Количество зависит от обеих частей ключа одновременно — оно описывает, сколько именно данного товара было в данной конкретной поставке, и не имеет смысла без обеих частей сразу. Частичной зависимости от одной части ключа нет. Аналогично проверена таблица Товары_в_продаже.
- При проверке таблицы Клиент было выявлено поле Количество бонусов. Хотя формально оно не нарушает 3НФ в классическом смысле (не зависит от другого поля этой же таблицы), было решено убрать его из соображений избыточности: это значение является производным — его можно вычислить как сумму по таблице Бонусные_операции (SUM по полю "Сумма баллов" с учётом типа операции — начисление/списание). Хранение одного и того же значения в двух местах создаёт риск рассинхронизации данных при обновлении. Поле удалено из таблицы Клиент.
Остальные таблицы (Товар, Поставщик, Поставка, Продажи, Уровень_лояльности, Бонусные_операции) проверены — все неключевые поля зависят непосредственно от первичного ключа, транзитивных зависимостей не обнаружено.

## Версионирование (SCD)
Версионирование реализовано через SCD3 в таблице Клиент: добавлены поля Код_уровня (текущий уровень лояльности) и Код_предыдущего_уровня (уровень до последнего изменения), оба — внешние ключи на Уровень_лояльности. Выбран SCD3, а не SCD2, так как для бизнес-задачи важно знать только текущий и непосредственно предыдущий уровень клиента, а не полную историю всех переходов — это упрощает модель и запросы, при этом не теряя ключевую информацию (откуда клиент пришёл на текущий уровень). Дата смены уровня не хранится, так как не требуется для решаемых задач.
Таблица Уровень_лояльности (пороги и проценты бонусов) версионированию не подвергалась и хранит только актуальные условия программы лояльности.

## Атрибуты таблиц
Товар
PK: Код товара
FK: Код поставщика → Поставщик.Код поставщика
Поставщик
PK: Код поставщика
FK: нет
Поставка
PK: Код поставки
FK: Код поставщика → Поставщик.Код поставщика
Товары_в_поставке
PK: составной (Код поставки, Код товара)
FK: Код поставки → Поставка.Код поставки
FK: Код товара → Товар.Код товара
Клиент
PK: Код клиента
FK: Код уровня → Уровень_лояльности.Код уровня
FK: Код предыдущего уровня → Уровень_лояльности.Код уровня
Продажи
PK: Код продажи
FK: Код клиента → Клиент.Код клиента
Товары_в_продаже
PK: составной (Код продажи, Код товара)
FK: Код продажи → Продажи.Код продажи
FK: Код товара → Товар.Код товара
Уровень_лояльности
PK: Код уровня
FK: нет
Бонусные_операции
PK: Код операции
FK: Код клиента → Клиент.Код клиента
FK: Код продажи → Продажи.Код продажи
