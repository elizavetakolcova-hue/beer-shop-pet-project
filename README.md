# beer-shop-pet-project
Пет-проект: БД пивного магазина с программой лояльности
# О проекте
Учебный проект представляет собой базу данных для пивного магазина, в котором есть программа лояльности. Поэтому эта база хранит данные как о товарах, которые продаются в магазине, так и о клиентах, зарегистрировавшихся в программе лояльности, начислении и списании бонусов.
Схема состоит из 9 таблиц:
- Товар, Поставщик, Поставка, Товары_в_поставке
- Клиент, Продажи, Товары_в_продаже
- Уровень_лояльности, Бонусные_операции

# Сценарии использования
Как запустить проект с нуля:

1. Создать пустую базу данных PostgreSQL
2. Выполнить DDL-скрипты из `scripts/` (создание таблиц) — 
   в порядке от независимых таблиц к зависимым
3. Выполнить `scripts/init_procedure.sql`, чтобы создать 
   процедуру инициализации
4. Вызвать `CALL init_beer_shop_data();` — заполнит все таблицы 
   тестовыми данными
5. Выполнить `scripts/indexes.sql` — создаст индексы
6. Выполнить запросы из `scripts/queries.sql` — можно по одному, 
   можно все сразу

Для повторного запуска процедуры инициализации на непустых 
таблицах — сначала выполнить `TRUNCATE` для всех таблиц 
(команда есть в комментарии в начале `init_procedure.sql`).

# Скрипты
Порядок выполнения файлов из `scripts/`:

| № | Файл | Что делает |
|---|---|---|
| 1 | `01_создание_таблиц.sql` (или как назвала) | DDL — создание всех 9 таблиц |
| 2 | `init_procedure.sql` | Создание процедуры инициализации данными |
| 3 | `queries_and_indexes.sql` | 17 запросов, демонстрирующих разные конструкции SQ и Создание индексов |

Ожидаемый результат: после выполнения всех скриптов по порядку 
база данных полностью наполнена тестовыми данными (15-60 строк 
на таблицу в зависимости от типа), и все запросы из `queries.sql` 
выполняются без ошибок.

Ограничения: скрипты рассчитаны на PostgreSQL (используют 
специфичный синтаксис — `SERIAL`, `CHECK`, `plpgsql`).
