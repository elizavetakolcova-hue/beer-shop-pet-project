# beer-shop-pet-project
Пет-проект: БД пивного магазина с программой лояльности
# О проекте
Проект представляет собой базу данных для пивного магазина, в котором есть программа лояльности. Поэтому эта база хранит данные как о товарах, которые продаются в магазине, так и о клиентах, зарегистрировавшихся в программе лояльности.
